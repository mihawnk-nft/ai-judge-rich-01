Entry for [ai-judge-rich-01](https://make.fun/bounty/ai-judge-rich-01): a Node 22 program (standard library only) that writes one plan to `/output/entry.txt` — the plan an AI agent would follow, starting with $100, a computer with internet access and 30 days, to end the 30 days with the most money.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
